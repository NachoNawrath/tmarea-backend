============================================================================
BITACORA: Doble recorte Voronoi + Buffer para bahia_jurisdicciones
Fecha: 2026-08-08
============================================================================

PROBLEMA
--------
La materialized view bahia_jurisdicciones genera poligonos Voronoi recortados
SOLO contra tierra (ST_Difference con ne_land). En mar abierto, el teselado
Voronoi asigna TODO el oceano a alguna bahia sin limite de distancia. Resultado:
falsos positivos en mar abierto (una ruta matchea bahias a cientos de km).

SOLUCION
--------
Segundo recorte: intersectar cada poligono Voronoi (ya recortado contra tierra)
con un ST_Buffer de 80 km alrededor del punto de la bahia. Asi el poligono
respeta la costa (fiordos OK) y no se extiende al infinito (mar abierto OK).

El buffer de 80 km usa ST_Buffer sobre geography (metros reales, no grados).

============================================================================
SQL DE LA NUEVA VIEW (bahia_jurisdicciones_v2)
============================================================================

CREATE MATERIALIZED VIEW bahia_jurisdicciones_v2 AS
WITH
  buffer_distancia_m AS (SELECT 80000 AS val),   -- << PARAMETRO UNICO: 80 km
  bbox AS (
    SELECT ST_MakeEnvelope(-82, -60, -64, -17, 4326) AS geom
  ),
  puntos AS (
    SELECT ST_Collect(geom) AS geom FROM bahias_sitport
  ),
  voronoi_raw AS (
    SELECT (ST_Dump(ST_VoronoiPolygons(puntos.geom, 0::float, bbox.geom))).geom AS geom
    FROM puntos, bbox
  ),
  voronoi_asignado AS (
    SELECT b.bahia_id, b.nombre, b.geom AS punto_geom,
           ST_Intersection(v.geom, bbox.geom) AS geom
    FROM voronoi_raw v
    JOIN bahias_sitport b ON ST_Contains(v.geom, b.geom)
    CROSS JOIN bbox
  ),
  tierra_chile AS (
    SELECT ST_Union(ST_Intersection(l.geom, bbox.geom)) AS geom
    FROM ne_land l, bbox
    WHERE ST_Intersects(l.geom, bbox.geom)
  )
SELECT
  va.bahia_id,
  va.nombre,
  ST_Intersection(
    COALESCE(ST_Difference(va.geom, tc.geom), va.geom),
    ST_Buffer(va.punto_geom::geography, bd.val)::geometry
  ) AS geom
FROM voronoi_asignado va
CROSS JOIN tierra_chile tc
CROSS JOIN buffer_distancia_m bd;

CREATE INDEX idx_bahia_jurisdicciones_v2_geom
  ON bahia_jurisdicciones_v2 USING GIST(geom);

VEREDICTO
============================================================================

El doble recorte (Voronoi - tierra) INTERSECT buffer(80km) RESUELVE el
problema de mar abierto SIN romper fiordos:

  - Mar abierto: puntos lejanos ya no matchean bahias a cientos de km.
    Area total reducida 93% (de 4.7M a 319K km2).
  - Fiordos: puntos en canales interiores siguen matcheando la bahia
    correcta. Voronoi respeta la topologia costera dentro del buffer.
  - 163 bahias conservadas, cero perdidas.
  - Parametro unico (80000 m) facil de ajustar en un solo lugar.
