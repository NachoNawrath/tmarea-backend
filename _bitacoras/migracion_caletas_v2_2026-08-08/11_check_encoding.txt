RESUMEN ENCODING

  CONCLUSION: El encoding UTF-8 del JSON es correcto. Las eñes se
  almacenan como C3 91 (Ñ mayuscula, 2 bytes UTF-8). No hay corrupcion.
  El caso "AYSEN" sin acento no es un problema de encoding sino del
  dato fuente de SUBPESCA (el campo region si dice "Aysen" con acento).

  Para el buscador de P2 esto no es problema: buscarCaletasLocal() hace
  normalize('NFD') + strip diacriticos, asi que buscar "aysen", "aysén"
  o "AYSEN" encontrara el registro igualmente.
